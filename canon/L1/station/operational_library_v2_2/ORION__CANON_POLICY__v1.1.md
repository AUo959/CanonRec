# ORION Canon Policy (v1.1.0)

Authority ladder: canonical > primary > reference > draft > run_output.

Rules:
- Nothing becomes canon by accident.
- Promotions are proposals logged in the Promotion Queue.
- Contradictions are logged in the Conflict Matrix (no silent blending).
- L3 symbols do not become literal L1 facts unless explicitly translated.

File-cap rule:
Prefer updating an existing canonical doc (version bump) over creating a new parallel doc.
