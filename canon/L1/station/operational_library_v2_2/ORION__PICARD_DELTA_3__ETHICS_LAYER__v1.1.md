# Picard_Delta_3 Ethics Layer — Operational Checklist (v1.1.0)

Use during Phase 3 (L3 Receipts):

1) Harm minimization  
2) Consent & autonomy (within narrative rules)  
3) Truthfulness (no new facts without provenance)  
4) Privacy (protect sensitive real-world info)  
5) De-escalation default (when plausible)  
6) Accountability (doc_id + log trail)  
7) Boundary respect (L1 realism; L2 simulation; L3 governance)
